# ECON1626 AI Future Forecast

Interactive ECON1626 Assessment 3 web essay: **The AI Food Chain Forecast**.

## Main Files

- `index.html` - GitHub Pages entry point.
- `forecast.html` - required assessment website file.

## Live Site

Live site: https://btboston.github.io/econ1626-ai-future-forecast/

Repository: https://github.com/BTBoston/econ1626-ai-future-forecast

## Topic

The essay forecasts how artificial intelligence could reshape agriculture, food supply chains, farmer bargaining power and food-system resilience by 2027-2030, using baseline, upside and downside scenarios plus an interactive simulator.

## AI-Enabled Method

AI assistance was used to structure the argument, refine the web design and build the illustrative simulator. Economic claims were checked against public sources listed in the website references.
